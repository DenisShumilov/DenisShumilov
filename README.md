# Денис Шумілов (`shmlv.`)

Розробляю локальні програмні інструменти для **перевірки інженерної документації**, аналізу телеметрії та цифрової обробки сигналів (**C++17 / Python / TypeScript**).

Основний підхід — явні правила перевірки, відтворюваний результат і посилання на вихідні докази.

## Перевірка документації та телеметрії

**[Відкрити інтерактивний стенд у браузері](https://denisshumilov.github.io/uav-readiness-evidence-copilot/)** · **[Репозиторій та код](https://github.com/DenisShumilov/uav-readiness-evidence-copilot)**

UAV Readiness & Evidence Copilot містить інструменти для звірки технічних пакетів (`.docx` / `.xlsx` / `.csv` / `.md`) та аналізу телеметрії (`.bin` / `.ulg` / `.ubx` / `.nmea`):

- **Перехресна звірка документів** — пошук розбіжностей у параметрах між Технічними умовами, Паспортом виробу, Програмою і методиками випробувань та Актом випробувань.
- **Узгодження таблиць** — виявлення числових суперечностей і формування узгодженого пакету за вибраним еталоном для подальшого інженерного перегляду.
- **Аналіз телеметрії** — перевірки навігаційних та апаратних аномалій і зміщення координат у логах. Результати потребують інженерної інтерпретації.
- **Матриця доказів** — розрахунок внутрішнього індексу повноти пакету з урахуванням відсутніх підтверджень та конфліктів.

Індекс інструмента не є сертифікацією, дозволом на експлуатацію або підтвердженням нормативної відповідності.

## Флагманські інженерні системи

### 1. [UAV Readiness & Evidence Copilot v2.2](https://github.com/DenisShumilov/uav-readiness-evidence-copilot) · [Живий стенд у браузері →](https://denisshumilov.github.io/uav-readiness-evidence-copilot/)
Локальна система автоматичної звірки конструкторської та експлуатаційної документації БпЛА (**ТУ ⇄ Паспорт ⇄ ПМВ ⇄ Акт випробувань** за вимогами Постанови КМУ №345) та передпольотної діагностики логів автопілота (`.bin` / `.ulg` / `.nmea` / `.ubx`).
- **Крос-документний аудитор та авто-узгодження (`defdoc_auditor.py` v2.2)**: нативний розбір таблиць `.docx` та `.xlsx` без сторонніх залежностей, виявлення числових колізій між документами та автоматичне вирівнювання пакету за еталоном ПМВ (`49/100 · ЗАБЛОКОВАНО` → `100/100 · ГОТОВО ДО ПОДАЧІ`).
- **Діагностика польотних логів та РЕБ (`telemetry_analyzer.py` v2.0)**: автоматичне виявлення спуфінгу GNSS (`C/N0` / стрибки висоти), втрати 3D-фіксації, розходження магнітометрів, просідання живлення та перевищення вібрацій рами + вбудований знеособлювач координат полігону (`--sanitize`).

### 2. `sndwch` — C++20/SIMD DSP-рушій обробки сигналів реального часу
Високопродуктивний низькорівневий C++20 аудіо/DSP-конвеєр без динамічних алокацій у потоці реального часу (`zero-allocation RT thread`), детермінована обробка буферів та спектральний аналіз сигналів.
